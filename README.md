# Slopvine
Slopvine is a tool that detects common signs of AI involvement in a Git repositories. It categorizes its findings into three tiers so users can judge the signal for themselves, which are **Worth Mentioning**, **Likely AI**, and **AI**.

## Project Status
This project is still in its very early stage, and core features have not yet been implemented. This README may not be updated frequently. To see which features are currently available, check the repo's commit history or run `slopvine help` using the binary built from the latest commit on the main branch.
